## 📚 Visão Geral

## 🎯 Objetivos da Aula
- Compreender o funcionamento de APIs (Application Programming Interface)
- Entender o protocolo HTTP e seus métodos (GET, POST, PUT, DELETE)
- Criar endpoints e trabalhar com JSON
- Desenvolver uma API RESTful com Express.js
- Implementar CORS para comunicação entre domínios
- Realizar deploy da API no Render
- Consumir a API no front-end

---

## 📋 Conteúdos Abordados

### Conceitos Fundamentais
- **API**: Interface de Programação de Aplicações
- **REST**: Representational State Transfer
- **HTTP**: Hypertext Transfer Protocol
- **Endpoints**: URLs específicas de acesso a recursos
- **JSON**: JavaScript Object Notation

### Métodos HTTP
| Método | Finalidade | Características |
|--------|-----------|-----------------|
| GET | Recuperar informações | Seguro, idempotente |
| POST | Criar novos recursos | Não idempotente |
| PUT/PATCH | Atualizar recursos | Substituição/Parcial |
| DELETE | Remover recursos | Idempotente |
